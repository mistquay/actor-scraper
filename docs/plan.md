# 已确认方案

用户已确认 FastAPI + 原生前端、公开 `mistquay/actor-scraper` 仓库与公开 GHCR 镜像。

1. 独立 Git 项目，复用演员资料与 GRAPHIS 图片抓取核心。
2. 常驻单容器 Web：管理登录、工作台、任务记录、连接与配置、演员结果预览。
3. `data/state.sqlite` 存配置/任务/结果，`data/cache` 存来源/图片缓存，`data/logs` 存轮转日志，手动导出进 `data/exports`。
4. 单个后台任务；冻结参数与演员范围，支持停止和失败/未完成重试。服务重启保留记录，中断任务可继续。
5. API 密钥保存在私有数据目录，浏览器读取配置不返回原密钥；同源管理会话与访问密码。
6. CLI 保留，默认存任务数据库，相对 JSONL 导出自动归入数据目录。
7. Actions 测试后构建 amd64/arm64 镜像，推送 GHCR；验证第一次构建和匿名拉取权限。

不加入定时订阅、媒体目录整理、演员实体合并或 FYMS 数据库改动。
